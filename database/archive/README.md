# Historial anterior a la baseline declarativa

Estos scripts reflejan migraciones ya aplicadas en BDComprasFertilizantes antes del proyecto SQL. Son evidencia histórica, no parte de la compilación o publicación con DACPAC.

No ejecutarlos para instalar una base nueva ni antes del proyecto: contienen precondiciones y auxiliares ligados al catálogo/instancia originales. Las pruebas actuales en ../tests usan una base desechable propia.

La fuente actual y única para nuevos cambios de objetos está en ../GestorFertilizantes.Database.
